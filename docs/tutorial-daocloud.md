# Развертывание в DaoCloud DevOps

Для небольших проектов и индивидуальных разработчиков поддержка собственной инфраструктуры GitLab CI и Docker Swarm может быть избыточной по ресурсам. В качестве альтернативы можно использовать облачную платформу DaoCloud.

## Основные шаги

### 1. Создание проекта

1. Перейдите в панель управления [DaoCloud](https://dashboard.daocloud.io).
2. Создайте новый проект и привяжите ваш репозиторий GitHub с кодом Hyperf.
3. DaoCloud автоматически добавит WebHook в GitHub для отслеживания push-событий.
4. При каждом коммите платформа автоматически выполнит сборку Docker-образа по `Dockerfile` вашего проекта.

### 2. Подключение кластера хостов

В разделе «Управление кластером» добавьте ваш целевой сервер (хост Linux), выполнив команду подключения агента DaoCloud.

### 3. Развертывание приложения

1. Перейдите в раздел «Приложения» -> «Создать приложение».
2. Выберите собранный образ проекта Hyperf.
3. Настройте проброс портов на хосте (например, порт `9501`).
4. Настройте подключение тома (Volume) для файла переменных окружения:
   - Путь в контейнере: `/opt/www/.env`
   - Путь на хосте: расположение вашего `.env` файла на сервере.
5. Нажмите «Развернуть».

### 4. Проверка

После запуска проверьте доступность сервиса:

```bash
curl http://127.0.0.1:9501/
# {"code":0,"data":{"user":"Hyperf","method":"GET","message":"Hello Hyperf."}}
```
