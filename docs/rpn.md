# Обратная польская нотация (RPN)

Компонент [hyperf/rpn](https://github.com/hyperf/rpn) реализует вычисление математических выражений методом обратной польской нотации (**R**everse **P**olish **N**otation, постфиксная запись). В RPN операторы следуют за операндами, что исключает неоднозначность приоритета операций и избавляет от необходимости использовать скобки.

## Установка

```bash
composer require hyperf/rpn
```

## Принцип работы алгоритма RPN

Стандартное инфиксное выражение `5 + ((1 + 2) * 4) - 3` в обратной польской нотации записывается как:

`5 1 2 + 4 * + 3 -`

Вычисление с использованием стека:

| Входной символ | Действие | Стек | Описание |
| :---: | :---: | :---: | :---: |
| 5 | Поместить в стек | 5 | |
| 1 | Поместить в стек | 5, 1 | |
| 2 | Поместить в стек | 5, 1, 2 | |
| + | Сложение | 5, 3 | Извлечь 1, 2, поместить результат (3) |
| 4 | Поместить в стек | 5, 3, 4 | |
| * | Умножение | 5, 12 | Извлечь 3, 4, поместить результат (12) |
| + | Сложение | 17 | Извлечь 5, 12, поместить результат (17) |
| 3 | Поместить в стек | 17, 3 | |
| - | Вычитание | 14 | Извлечь 17, 3, поместить результат (14) |

Итоговый результат на вершине стека: `14`.

## Использование

### Прямое вычисление RPN выражения

```php
<?php
use Hyperf\Rpn\Calculator;

$calculator = new Calculator();
$result = $calculator->calculate('5 1 2 + 4 * + 3 -', []); // '14'
```

### Настройка точности вычислений (scale)

```php
<?php
use Hyperf\Rpn\Calculator;

$calculator = new Calculator();
$result = $calculator->calculate('5 1 2 + 4 * + 3 -', [], 2); // '14.00'
```

### Использование переменных в выражениях

```php
<?php
use Hyperf\Rpn\Calculator;

$calculator = new Calculator();
$result = $calculator->calculate('[0] 1 2 + 4 * + [1] -', [5, 10]); // '7'
```

### Преобразование инфиксного выражения в постфиксное (RPN)

```php
<?php
use Hyperf\Rpn\Calculator;

$calculator = new Calculator();
$rpn = $calculator->toRPNExpression('4 - 2 * ( 5 + 5 ) - 10'); 
// Результат: '4 2 5 5 + * - 10 -'
```
