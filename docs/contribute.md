# Участие в разработке (Contribute)

Hyperf — полностью открытый проект сообщества. Развитие фреймворка напрямую зависит от вклада разработчиков со всего мира.

## С чего начать участие?

1. **GitHub Issues**: Следите за страницей [Issues](https://github.com/hyperf/hyperf/issues), помогайте отвечать на вопросы новичков и воспроизводить найденные баги.
2. **Pull Requests**: Если вы нашли ошибку или хотите предложить улучшение функционала, создайте форк репозитория [hyperf/hyperf](https://github.com/hyperf/hyperf), внесите изменения с тестами и отправьте [Pull Request](https://github.com/hyperf/hyperf/pulls).
3. **Ревью кода**: Участвуйте в обсуждении и рецензировании Pull Request других участников сообщества.
4. **Разработка экосистемных компонентов**: Создавайте новые компоненты и расширения для Hyperf и делитесь ими с сообществом.
5. **Документация и переводы**: Улучшайте документацию, исправляйте опечатки и дополняйте примеры кода.

## Вступление в команду ядра (Core Team)

Команда ядра Hyperf занимается постоянной разработкой фреймворка и развитием сопутствующих проектов. 

Критерии для приглашения в состав команды Hyperf:
- Не менее 100 содержательных коммитов в репозиторий [hyperf/hyperf](https://github.com/hyperf/hyperf) либо авторство значимого компонента в экосистеме Hyperf.
- Номинация действующим участником команды и поддержка более 50% членов команды.

### Преимущества участников Core Team:
- Почтовый ящик в домене `@hyperf.io`
- Подписка на полный пакет инструментов JetBrains All-Products Pack
- Статус участника организации Hyperf на GitHub
