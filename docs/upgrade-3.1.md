# Руководство по обновлению до 3.1

## Ключевые изменения в версии 3.1

- Минимальные системные требования повышены: **PHP >= 8.1** и **Swoole >= 5.0**.
- Официальная интеграция тестового фреймворка [Pest](https://pestphp.com/).
- Добавлен пакет `hyperf/helper`: глобальные функции-хелперы без пространств имен вынесены из `Hyperf\Utils` в отдельный пакет `hyperf/helper`.
- В компоненте `hyperf/config` добавлена поддержка загрузки многоуровневых вложенных файлов конфигураций через точечный синтаксис (например, `config('sub.item')`).

---

## 1. Изменения в пакете вспомогательных функций (Utils)

Раньше глобальные функции-хелперы находились в пространстве имен пакета `utils` без префикса, что иногда приводило к конфликтам имен со сторонними библиотеками. В 3.1 они были удалены из базового `utils`.

Два варианта адаптации:
1. Если конфликтов нет, просто установите отдельный пакет `hyperf/helper`:
   ```bash
   composer require hyperf/helper
   ```
2. Либо выполните автоматический рефакторинг вызовов с добавлением пространств имен с помощью `rector`.

---

## 2. Загрузка многоуровневых конфигурационных файлов

В Hyperf 3.0 ключом конфигурации являлось имя файла. В версии 3.1 файлы во вложенных поддиректориях `config/autoload/` загружаются с учетом пути: `относительная_директория.имя_файла`:
- Если у вас был файл `config/autoload/sub/a.php`, то вместо `config('a')` теперь используется `config('sub.a')`.
- Имена файлов с точками (например, `config/autoload/a.b.php`) преобразуются во вложенный массив `b` внутри ключа `a`.

---

## 3. Другие важные изменения

### Компонент метрик (Metric)

Пакет `hyperf/metric` больше не устанавливает зависимость `promphp/prometheus_client_php` по умолчанию. Если вы используете Prometheus, установите драйвер вручную:

```bash
composer require promphp/prometheus_client_php
```

### Поведение метода `withHeaders` в Request и Response

До версии 3.1 метод `withHeaders()` объединял заголовки с существующими (подобно `array_merge`). Начиная с 3.1, вызов `withHeaders()` полностью заменяет все предыдущие заголовки:

```php
// В версии 3.1:
$request->withHeaders(['foo' => 1])->withHeaders(['bar' => 2]); 
// Результат: ['bar' => [2]]
```

### Возвращаемый тип в методе потребителя AMQP

В методе `consumeMessage` класса потребителя сообщений AMQP возвращаемый тип изменен со строки на перечисление `Hyperf\Amqp\Result`:

```php
// До 3.1:
public function consumeMessage($data, AMQPMessage $message): string

// Начиная с 3.1:
public function consumeMessage($data, AMQPMessage $message): \Hyperf\Amqp\Result
{
    return \Hyperf\Amqp\Result::ACK;
}
```
